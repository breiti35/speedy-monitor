# Speedy Monitor 1.1.0

**English** · [Deutsch](#deutsch)

## What's new

- **English user interface.** Speedy Monitor now speaks English and German. By default it follows
  your Windows language; you can switch it in the settings under "Sprache / Language".
- The setup is bilingual as well and picks the language automatically.

## Download

| File | Size | For whom |
|---|---|---|
| `SpeedyMonitor_Setup_1.1.0.exe` | approx. 2.4 MB | If the [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0) is already installed. The setup checks for it and otherwise offers the download. |
| `SpeedyMonitor_Setup_1.1.0_Standalone.exe` | approx. 47 MB | Works without any prerequisites – if in doubt, take this one. |

Updating: just run the new setup. Your settings and statistics are kept.

> **About the Windows warning:** the setup is not digitally signed, so Windows SmartScreen shows
> "Windows protected your PC". Click "More info" and then "Run anyway".

## Deutsch

### Neu

- **Englische Oberfläche.** Speedy Monitor spricht jetzt Englisch und Deutsch. Standardmäßig richtet
  es sich nach deiner Windows-Sprache; umstellen kannst du das in den Einstellungen unter
  „Sprache / Language“.
- Auch das Setup ist zweisprachig und wählt die Sprache automatisch.

### Download

| Datei | Größe | Für wen |
|---|---|---|
| `SpeedyMonitor_Setup_1.1.0.exe` | ca. 2,4 MB | Wenn die [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0) schon installiert ist. Das Setup prüft das und bietet sonst den Download an. |
| `SpeedyMonitor_Setup_1.1.0_Standalone.exe` | ca. 47 MB | Funktioniert ohne weitere Voraussetzungen – im Zweifel diese nehmen. |

Update: einfach das neue Setup ausführen. Einstellungen und Statistik bleiben erhalten.
Die Anleitung mit Screenshots: [Anleitung](https://github.com/breiti35/speedy-monitor/blob/master/docs/ANLEITUNG.md).

> **Hinweis zur Windows-Warnung:** Das Setup ist nicht digital signiert. Windows SmartScreen zeigt
> deshalb „Der Computer wurde durch Windows geschützt“. Auf „Weitere Informationen“ und dann
> „Trotzdem ausführen“ klicken.
